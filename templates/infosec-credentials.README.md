## Records

Records are organized by issuer:

- `records/google/`
- `records/fortinet/`
- `records/cisco/`
- `records/comptia/`
- `records/offsec/`
- `records/ec-council/`
- `achievements/`

Create an issuer directory when its first record is ready.
Each credential gets a `YYYY-MM-credential-slug.md` record.
Public certificate copies, when appropriate, use the same basename.

## Verification and privacy

Verification links point to the issuer, its authorized credential platform,
or a public record from the authorized training provider.
A certificate image alone is not independent verification.

Dates use ISO 8601: `YYYY-MM-DD`.
Status reflects the issuer's record at the last review.
Renewals and expiration dates are recorded explicitly.

Public files exclude unnecessary personal data, private identifiers,
exam materials, and private verification links.
